# System Overview

## Release Information

- **Version**: 1.0.0

- **Certified**: Yes

- **Publisher**: Fortinet

- **Compatibility**: FortiSOAR 8.0.0 and later

- **Applicable**: Dashboard

## Overview

The **System Overview** widget displays real-time health and performance data for your FortiSOAR instance directly on a dashboard. It supports two broad monitoring perspectives — platform health and application monitoring — each offering focused views into different aspects of system operation.

Use the **System Overview** widget to keep critical infrastructure metrics visible at a glance, so analysts and administrators can quickly assess the state of the FortiSOAR platform without navigating away from the dashboard.

### Key Features

- Monitor overall platform health, including CPU, memory, and storage metrics
- View the status of FortiSOAR services grouped by category
- Track connector availability across all configured integrations
- Monitor playbook execution activity, including queued and executed workflow counts
- Configure multiple instances of the widget on a single dashboard, each scoped to a different monitoring type
- Customize color coding for CPU, memory, and disk metrics when monitoring platform health
